## Phạm vi và hợp đồng

P0-02 tạo hai client TypeScript độc lập trong monorepo, mỗi app có manifest, lockfile, README và script kiểm tra riêng:

- `mobile/`: Expo SDK 53, React Native 0.79.5, React 19.0.0, TypeScript 5.8.3. Điều hướng bằng `@react-navigation/native-stack`, trạng thái bằng `zustand`, lưu token bằng `expo-secure-store`.
- `admin-web/`: React 18.3.1, Vite 6.3.5, React Router 6.30.1, `zustand`. Test bằng Vitest và jsdom.

UI Kit nằm ở hai lớp:

- `admin-web/src/style.css` giữ token CSS (`--color-*`, `--space-*`, `--radius-*`) và class dùng chung như `.panel`, `.button`, `.button-primary`, `.error`.
- `mobile/src/theme.ts` giữ token `colors`, `space`, `radius`, `text` cho toàn bộ 5 màn hình và thanh điều hướng.

Hai lớp dùng chung một bảng màu gốc. `style.css` khai báo 8 màu (`ink` `#222a27`, `ink-soft` `#3a4740`, `muted` `#6b716d`, `brand` `#a7442e`, `danger` `#a12d24`, `line` `#e3e4df`, `surface` `#fff`, `canvas` `#f5f4ef`), 6 bậc khoảng cách 4/8/12/16/24/40, 2 bậc bo góc 6/10. `theme.ts` khai báo 6 màu đang dùng (`ink`, `muted`, `brand`, `line`, `surface`, `danger`), 5 bậc khoảng cách 4/8/12/16/24 và 1 bậc bo góc 10. Chưa tách package dùng chung vì hai nền tảng khác hệ style (CSS và StyleSheet), tách ra chỉ thêm một lớp build mà chưa có nơi thứ ba sử dụng.

Hợp đồng phía client:

| Client | Đầu vào môi trường | Cách gọi API | Xử lý 401 |
|---|---|---|---|
| Web | `VITE_API_URL` (bắt buộc) | `admin-web/src/api/client.ts`, gắn `Authorization: Bearer` từ `sessionStorage` | Xóa token, phát sự kiện `session-expired`, `AuthProvider` đưa về màn đăng nhập |
| Mobile | `EXPO_PUBLIC_API_URL` (bắt buộc) | `mobile/src/api/client.ts`, gắn `Authorization: Bearer` từ `expo-secure-store` | Xóa token, đặt lại `useSession` |

Gốc API là `http://localhost:8082/api/v1`, khớp cổng và tiền tố của backend P0-01. Client gọi đường dẫn tương đối như `/auth/me`, `/listings`. Thiếu biến môi trường thì client ném lỗi ngay, không gọi mạng.

Web phân quyền giao diện theo bảng `admin-web/src/config/rolePages.ts`: `admin` thấy tổng quan, người dùng, giao dịch, danh mục; `moderator` thấy tổng quan, tin đăng, báo cáo; `seller` thấy tổng quan, tin đăng của tôi. Route ngoài quyền bị `ProtectedPage` chuyển hướng, không gọi API.

### Cách thử

```bash
# Web
cd admin-web
npm ci
npm run lint      # tsc --noEmit
npm test          # 5 test đạt
npm run build     # tsc -b && vite build
npm run dev       # http://localhost:5173

# Mobile
cd mobile
npm ci
npm run lint      # tsc --noEmit
npm test          # 5 test đạt
npm start         # Expo dev server
```

Chép `.env.example` thành `.env` ở từng app trước khi chạy dev.

Với giả lập, kiểm tra đường mạng trước khi mở app. LDPlayer không đi qua `10.0.2.2` mà dùng IP LAN của máy, ví dụ `http://192.168.1.73:8082/api/v1`. Xác nhận bằng:

```bash
adb shell "curl -s http://192.168.1.73:8082/api/v1/health"
```

Expo Go cài bằng `adb install -r ExpoGo-<sdk>.apk`, sau đó mở `exp://127.0.0.1:8081` sau khi đã chạy `adb reverse tcp:8081 tcp:8081`.
