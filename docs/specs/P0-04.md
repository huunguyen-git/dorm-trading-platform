## Phạm vi bàn giao

P0-04 thiết lập toàn bộ quy trình CI/CD ban đầu cho kho lưu trữ trên GitHub Actions:
1. **Kiểm tra repo và mã nguồn (`repository` job):** Kiểm tra lỗi khoảng trắng dư thừa trên dải commit của PR bằng `git diff --check`, ngăn ngừa ký tự xung đột merge.
2. **Kiểm tra cú pháp workflow (`workflow-lint` job):** Lint toàn bộ các tệp workflow Actions bằng Docker `rhysd/actionlint:1.7.12` ở chế độ read-only.
3. **Biên dịch và kiểm thử Backend (`backend` job):** Tự động cài đặt Temurin JDK 21 LTS trên `ubuntu-latest`, bật cache Maven, cấp quyền thực thi cho Unix wrapper, chạy `./mvnw --batch-mode --no-transfer-progress clean verify` và lưu trữ báo cáo Surefire dưới dạng artifact.
4. **Cổng kiểm duyệt hợp nhất (`required` job):** Gom trạng thái của tất cả các job bắt buộc (`needs: [repository, workflow-lint, backend]`), kết xuất bảng Markdown trực quan vào GitHub Actions Step Summary.
5. **Cấu hình bảo mật và vệ sinh mã nguồn:** Thiết lập `.editorconfig` đồng bộ UTF-8/LF, `.github/dependabot.yml` tự động quét phụ thuộc Actions và Maven hàng tuần, và `.github/pull_request_template.md` chuẩn hóa biểu mẫu PR.

## Hướng dẫn chạy thử và kiểm tra cục bộ

```bash
# 1. Kiểm tra lỗi khoảng trắng trước khi commit
git diff --check

# 2. Kiểm thử Backend cục bộ
cd backend
.\mvnw.cmd clean verify   # Trên Windows
./mvnw clean verify       # Trên Linux / macOS
```
