## Phạm vi và hợp đồng

1. **Hạ tầng Docker Compose (`docker-compose.yml`)**:
   - `postgres`: PostgreSQL 16 Alpine, cổng `5432:5432`, volume dữ liệu `postgres_data`, script khởi tạo `infra/docker/postgres/init-db.sql`.
   - `maildev`: SMTP cổng 1025, Web UI cổng 1080 phục vụ kiểm tra gửi email kích hoạt và mã OTP.
   - `minio`: S3-compatible Object Storage cổng 9000 (API) và 9001 (Web Console), lưu trữ hình ảnh vật phẩm và thẻ SV.
   - Cung cấp file cấu hình mẫu `.env.example`.

2. **Cơ sở dữ liệu và Migration Flyway**:
   - `V1__init_schema.sql`: Khởi tạo 15 bảng thực thể miền (vai_tro_quan_tri, thanh_viens, danh_mucs, do_vats, tin_dangs, tin_dang_do_vat, hoi_thoais, tin_nhans, giao_dichs, ma_xac_nhan_otp, danh_gias, bao_caos, khieu_nais, quyet_dinhs, thang_phats). Thiết lập các khóa chính, khóa ngoại, ràng buộc NOT NULL, UNIQUE và CHECK cho trạng thái enum.
   - `V2__seed_initial_data.sql`: Nạp sẵn dữ liệu ban đầu gồm 7 danh mục vật phẩm KTX và vai trò hệ thống.

3. **Mở rộng Endpoint Health Check**:
   - `GET /api/v1/health`:
     - Giữ nguyên hợp đồng P0-01 (`status: "UP"`, `service: "dorm-trading-backend"`, `timestamp: "..."`).
     - Bổ sung trường `"database": "CONNECTED"` khi CSDL sẵn sàng và kết nối thành công.

4. **Kiểm thử Tích hợp Độc lập (Testcontainers)**:
   - `PostgresTestContainer`: Áp dụng Singleton pattern khởi chạy một container PostgreSQL 16 độc lập cho toàn bộ suite test.
   - Profile `default`: Tắt DB auto-configuration để `ApiSecurityTest` chạy siêu nhanh và độc lập mà không cần môi trường DB thật.
   - Profile `test`: Kích hoạt Flyway tự động migrate toàn bộ schema lên Testcontainers và chạy các test tích hợp.

## Hướng dẫn manual test trên Windows

### Cửa sổ PowerShell 1 · Bật hạ tầng Docker

```powershell
docker compose up -d
docker ps
```

Kiểm tra 15 bảng và dữ liệu 7 danh mục đã tạo trong container:

```powershell
docker exec -it dorm-postgres psql -U dorm_user -d dorm_trading -c "\dt"
docker exec -it dorm-postgres psql -U dorm_user -d dorm_trading -c "SELECT ma_danh_muc, ten FROM danh_mucs;"
```

### Cửa sổ PowerShell 2 · Chạy toàn bộ Test Suite

```powershell
cd backend
$env:JAVA_HOME = "C:\Users\Nguyen\.jdks\jdk-21.0.6+7"
.\mvnw.cmd clean test
```
