# Danh mục Ca sử dụng (Use Cases)

Tài liệu đặc tả ca sử dụng của hệ thống Sàn giao dịch đồ dùng sinh viên được phân rã chi tiết thành 40 file markdown độc lập trong thư mục [`docs/use-cases/`](use-cases/README.md).

Toàn bộ thông tin về Actor, Luồng chính, Luồng thay thế, Ngoại lệ, Tiền điều kiện và Hậu điều kiện được chuẩn hóa và quản lý tập trung trong repo, không phụ thuộc vào bất kỳ file tài liệu bên ngoài nào.
